## 📌 Project Overview
Concert-grade event production portfolio for DVR Sound & Event Shahdol. Features an audio waveform pulsing into a stage-light sweep startup animation, Line Array & P3 LED Wall packages, audio visualizer simulator, and interactive event quote estimator.

This trial demo website was engineered following the **SHIV Revised No Standalone Website Prospects Research (November 2026)** to demonstrate how a bespoke, high-performance web presence elevates conversion, brand authority, and client inquiries compared to bare social media pages.

---

## ✨ Key Features & Experience

- **⚡ Sub-900ms Skippable Startup Animation**: Branded SVG monogram animation respecting `prefers-reduced-motion` without blocking navigation.
- **📱 100% Mobile-First Responsive**: Designed from 360px mobile viewports up to 4K ultra-wide monitors using fluid CSS clamping and flexible grids.
- **💬 Direct WhatsApp Conversion Engine**: Instant, pre-filled WhatsApp inquiry buttons connecting customers directly to business contact channels.
- **🛡️ Demo Integrity Compliance**: Non-intrusive concept banner informing visitors that this is an independent portfolio showcase, with zero online transaction liabilities.
- **🔍 Full Local & Category SEO**:
  - Embedded JSON-LD structured data (`EntertainmentBusiness, LocalBusiness`).
  - Open Graph & Twitter Cards for social sharing previews.
  - Native `sitemap.xml` and `robots.txt` for instant search indexing.
