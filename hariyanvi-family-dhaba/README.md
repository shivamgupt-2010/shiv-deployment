## 📌 Project Overview

High-conversion highway family dhaba website designed to drive travelers and local families directly to the dhaba. Features instant GPS map routing, family cottage reservation, and live menu pricing.

This trial demo website was engineered following the **SHIV Local Business Prospecting & Digital Transformation Framework (November 2026)** to demonstrate how a bespoke, high-performance web presence elevates conversion, local brand authority, and client acquisition compared to bare social media profiles.

---

## ✨ Key Features & Experience

- **⚡ Sub-900ms Skippable Startup Animation**: Branded monogram SVG animation respecting `prefers-reduced-motion` without blocking navigation.
- **📱 100% Mobile-First Responsive**: Engineered from 360px mobile viewports up to 4K ultra-wide monitors using fluid CSS clamping and flexible grids.
- **💬 Direct WhatsApp Conversion Engine**: Instant, pre-filled WhatsApp inquiry forms connected directly to **SHIV Web Studio** (`+91 6267686575`).
- **🛡️ Demo Integrity Compliance**: Non-intrusive concept banner informing visitors that this is an independent portfolio showcase.
- **🔍 Full Local SEO & Rich Snippets**:
  - Embedded JSON-LD structured data (`Restaurant`).
  - Open Graph & Twitter Cards for social sharing previews.
  - Native `sitemap.xml` and `robots.txt` for instant search indexing.
