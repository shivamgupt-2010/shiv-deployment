## 📌 Project Overview

**Lakshmi Saree Sansar** is an editorial-grade, visually stunning digital showcase engineered by **SHIV Web Studio** for a premier saree boutique located at Shraja Mall, Burhar, Madhya Pradesh.

Inspired by royal Indian luxury ateliers (Sabyasachi, Raw Mango) and contemporary fashion editorials, this concept demonstrates how a high-converting web storefront elevates local retail authority, preserves traditional textile heritage, and funnels bridal clientele directly into in-store consultations and WhatsApp sales.

---

## ✨ Key Features & Interactive Architecture

- **⚡ Fabric-Inspired Silk Opening Reveal**: A gold thread and silk-ribbon weave animation (<850ms, skippable, respecting `prefers-reduced-motion`) revealing the brand monogram before smoothly presenting the hero drape.
- **🎨 Editorial Color System**: Deep Wine (`#4a0e17`), Ivory (`#fdfbf7`), Champagne Gold (`#d4af37`), and Warm Beige (`#f5ebe0`).
- **🥻 Signature Weave Categories**: Royal Banarasi Katan, Kanjivaram Temple Weaves, Chanderi Zari Tissue, Handcrafted Organza, Pure Georgette, and Bridal Trousseaus.
- **🔍 Interactive Product Modal**: Detailed weave story, fabric composition (100% pure silk, Silk Mark certified), zari grade, running blouse piece dimensions, and direct WhatsApp stylist inquiry.
- **🛍️ Simulated Shopping Bag & Checkout**: Fully interactive slide-out cart drawer, live subtotal computation, and simulated checkout flow with zero monetary transaction liability.
- **📅 VIP Bridal Drape Trial Booking**: Interactive appointment scheduling module that compiles customer preference, occasion, and visit date into a prefilled WhatsApp inquiry.
- **🛡️ Concept Integrity & SHIV Branding**: Prominent concept demo banners, watermark badges, and direct developer attribution (`+91 6267686575`).
